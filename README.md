# EventManager

Aplicación móvil para la creación, administración y participación
en eventos, desarrollada originalmente como proyecto académico y
posteriormente modernizada para utilizar tecnologías actuales.

## Tecnologías

- Angular
- Ionic
- Capacitor
- TypeScript
- Node.js
- REST API
- Android
- Render

## Funcionalidades

- Registro e inicio de sesión
- Gestión de sesiones
- Creación y edición de eventos
- Portadas personalizadas
- Lectura de códigos QR
- Perfil de usuario
- Gestión de eventos
- API REST desplegada en Render
- Aplicación Android mediante Capacitor

## Seguridad

- Contraseñas almacenadas mediante hashing
- Cookies HttpOnly
- Autorización en backend
- Protección CORS
- Rate limiting
- Validación de entradas
